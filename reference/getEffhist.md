# Calculate historical fishing mortality

Calculate historical fishing mortality

## Usage

``` r
getEffhist(Esd, nyears, EffYears, EffLower, EffUpper)
```

## Arguments

- Esd:

  vector of standard deviation

- nyears:

  number of years

- EffYears:

  index of years

- EffLower:

  vector of lower bound

- EffUpper:

  vector of upper bound
