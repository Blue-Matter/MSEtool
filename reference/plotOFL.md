# A generic OFL plot for NOAA use

As title.

## Usage

``` r
plotOFL(Data, xlims = NA, perc = 0.5)
```

## Arguments

- Data:

  An object of class Data that has been run though TAC()

- xlims:

  x axis limits

- perc:

  The percentile of the OFL distribution to be plotted

## Value

A table of performance metrics.
