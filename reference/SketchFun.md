# Manually map the historical relative fishing effort trajectory.

Internal function for interactive plot which allows users to specify the
relative trajectory and variability in the historical fishing effort.

## Usage

``` r
SketchFun(nyears, Years=NULL)
```

## Arguments

- nyears:

  Number of years

- Years:

  An optional vector of years. Should be nyears long.
