# Show MSEtool S4 objects

Briefly prints a couple of lines from
[str](https://rdrr.io/r/utils/str.html) to avoid swamping the console
with the contents of very large objects.

## Usage

``` r
# S4 method for class 'Data'
show(object)

# S4 method for class 'OM'
show(object)

# S4 method for class 'Hist'
show(object)

# S4 method for class 'MSE'
show(object)

# S4 method for class 'MMSE'
show(object)

# S4 method for class 'MOM'
show(object)
```

## Arguments

- object:

  S4 object from MSEtool
