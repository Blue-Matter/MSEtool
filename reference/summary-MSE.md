# Summary of MSE object

Summary of MSE object

## Usage

``` r
# S4 method for class 'MSE'
summary(object, ..., silent = FALSE, Refs = NULL)
```

## Arguments

- object:

  object of class MSE

- ...:

  a list of names of PM methods

- silent:

  Should summary be printed to console? Logical.

- Refs:

  An optional named list (matching the PM names) with numeric values to
  override the default `Ref` values. See examples.
