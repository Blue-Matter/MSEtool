# Internal function to create a blank plot for mapping selectivity at length

Internal function to create a blank plot for mapping selectivity at
length

## Usage

``` r
BlankSelPlot(Stock = NULL, Yr = NULL, N = NULL, isRel)
```

## Arguments

- Stock:

  Stock object. If provided, average length-at-maturity is included on
  plot for reference.

- Yr:

  Year number

- N:

  Year index

- isRel:

  Logical. Are selectivity parameters relative to length of maturity?
