# Utility functions for multiMSE objects

`addMMPs()` adds additional management procedures to a MMSE object by
combining multiple MMSE objects that have identical historical OM
values, and population/ fleet structures.

## Usage

``` r
addMMPs(MMSEobjs)
```

## Arguments

- MMSEobjs:

  A list `MMSE` object

## Value

An object of class `MMSE`
