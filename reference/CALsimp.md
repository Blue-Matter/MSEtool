# Simplifies the CAL slot of data object

A function that condenses the number of catch-at-length bins in a data
object

## Usage

``` r
CALsimp(Data, nbins = 10, simno = 1)
```

## Arguments

- Data:

  An object of class 'Data'.

- nbins:

  Integer. The target number of catch at length bins

- simno:

  Integer. An optional argument to specify the simulation number if
  writing simulated data
