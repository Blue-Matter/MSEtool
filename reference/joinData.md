# Join Data objects present in a list

A function that combined a list of data objects into a single data
object (same dimensions but can have different numbers of simulations)

## Usage

``` r
joinData(DataList)
```

## Arguments

- DataList:

  A list of data objects of identical dimension (except for simulation)
