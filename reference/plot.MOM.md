# Standard plot for an object of class MOM

Plot the stocks, fleets, catch fractions and relationships in multi
operating model object

## Usage

``` r
# S4 method for class 'MOM,missing'
plot(x, silent = TRUE, maxsims = 6)
```

## Arguments

- x:

  Object of class
  [MOM](https://msetool.openmse.com/reference/MOM-class.md). A Multi-OM
  object created by `new('MOM', ...)`

- silent:

  Logical. Do you wish to see print outs / warnings?

- maxsims:

  Integer. What are the maximum number of individual simulations you
  wish to plot?
