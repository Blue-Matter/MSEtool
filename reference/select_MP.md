# Select DataList for an MP from `MMSE@PPD`

Select DataList for an MP from `MMSE@PPD`

## Usage

``` r
select_MP(PPD, MP = 1)
```

## Arguments

- PPD:

  `PPD` slot from an MMSE object

- MP:

  Numeric value indicating the MP to return DataList

## Value

A nested list `Data` objects (`nstock` by `nfleet`)
