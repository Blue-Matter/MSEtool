# Creates a time series per simulation that has a random normal walk with sigma

Creates a time series per simulation that has a random normal walk with
sigma

## Usage

``` r
GenerateRandomWalk(targ, targsd, nyears, nsim, rands = NULL)
```

## Arguments

- targ:

  mean

- targsd:

  standard deviation

- nyears:

  number of years to simulate

- nsim:

  number of simulations
