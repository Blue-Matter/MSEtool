# A basic SSB plot for debugging runMSE output

A basic SSB plot for debugging runMSE output

## Usage

``` r
plotmulti(MSEmulti, maxsim = 8)
```

## Arguments

- MSEmulti:

  An object of class MMSE arising from a run of multiMSE(MOM, ...)

- maxsim:

  Integer. The number of simulations to plot
