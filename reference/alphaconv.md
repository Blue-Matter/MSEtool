# Calculate parameters for beta distribution from mean and standard deviation in normal space

Calculate parameters for beta distribution from mean and standard
deviation in normal space

## Usage

``` r
alphaconv(m, sd)

betaconv(m, sd)
```

## Arguments

- m:

  mean

- sd:

  standard deviation

## Value

numeric

## Functions

- `alphaconv()`: Returns alpha of beta distribution

- `betaconv()`: Returns beta of beta distribution
